2The Solution — DualChunkSwap Token Assignment
Give each rank one "early" chunk (light work) and one "late" chunk (heavy work). They cancel out — every rank does equal total work.
How DualChunkSwap assigns tokens (ws=4, S=16, chunk=2)
Divide the sequence into 2×ws = 8 chunks. Rank r gets chunk r (HEAD, from the first half) and chunk 2×ws−r−1 (TAIL, from the second half — mirrored order).

Why iris_cp.py does the extra Q AllGather: With DualChunkSwap, each rank's Q tokens are non-contiguous in the sequence (e.g. Rank 0 has positions 0,1,14,15). Running causal attention with local Q against the full global K would require per-token causal masks — not a simple prefix slice. The simplest correct solution is to AllGather Q, restore everything to sequential order, and run standard causal flash attention on the global sequence. This is what iris_cp.py currently does. The optimal solution (using the head/tail two-pass directly) is in the metadata builder but not yet wired to the forward pass.
